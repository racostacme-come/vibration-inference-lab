# Concept provenance and originality

Read-only inspection on 8 October 2026 covered the DTU ATSA, MLSP and MMME
source folders. No course document, exercise solution, dataset or lecture image
is included in this repository.

The primary source of topic selection was DTU **02427 Advanced Time Series
Analysis**, Lecture 6, *Hierarchical forecast reconciliation*, dated 2026.
The actual lecture covers heat-load forecasting, aggregation constraints,
covariance weighting, shrinkage and general linear models. The lecture PDF was
added locally on 7 October. Its companion lecture concerns multivariate
probabilistic forecast evaluation; that broader topic is outside this project.

The other inspected sources were the MLSP introductory signal-processing chapter
(continuous/discrete signals and linear systems) and MMME course 41747 Lecture 4
notes (explicit heat-diffusion stability and interface matching). These confirm
available rotation topics; this project does not implement their exercises.

The synthetic four-building network, error factors, sample sizes, seeds,
experiments, code, figures and prose were written for this project. The geometry
has no connection to a real district. Public methodological references are
listed in the README and paper. The implementation studies an established
method and makes no methodological novelty or peer-review claim.

All work remains under the series directory in the TUM Courses workspace.
DTU source folders and unrelated repositories were not modified.
